About MedAI Arena

Arena Elo Scoring

Rankings use the Elo rating system adapted from chess and LMSYS Chatbot Arena, reflecting relative model performance from expert pairwise comparisons.

Expert-Driven Evaluation

Scores are derived from votes by medical professionals and AI researchers, ensuring evaluations reflect real-world clinical utility.

Open Source

All data and code are publicly available. Submit a model via GitHub issue or contribute improvements to the platform directly.

About

MedAI Arena is an open-source project dedicated to benchmarking medical AI models. We use a combination of automated benchmarks and expert human evaluation.
